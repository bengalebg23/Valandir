# Valandir campaign vault

Obsidian vault of Ben's D&D campaign notes for the Valandir campaign. This is not code. It's markdown notes, attachments and battle maps, synced through this repo.

## Rules
- Write notes as Obsidian markdown: `[[wikilinks]]` between notes, YAML front matter where existing notes use it, and images in `Z_Attachments/`.
- Match the existing folder structure and note style. Look at neighbouring notes before creating new ones.
- Don't touch `.obsidian/` (app settings) or `.trash/` unless Ben asks.
- Don't rename or move notes casually, because that breaks wikilinks across the vault.
- Ben is often the DM, so these notes may contain spoilers and secrets for players. Never post note content anywhere outside this repo.
- Commit to `master` with a short message saying which notes changed.
